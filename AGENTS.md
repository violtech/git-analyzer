## Using the analytics without the UI

Every dashboard action has a CLI command and a REST endpoint that return the same numbers as JSON. Start with
`npm run ga -- describe`, and read [HEADLESS.md](HEADLESS.md) before quoting any figure (the AI share is a lower bound and
line counts are estimates).
